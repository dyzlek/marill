# La Bibliothèque de Babel en réseau

Projet fil rouge du BUT MMI 3 (R5.06 Back en Laravel, R5.05 Front en Angular), IUT de Béziers.

Chaque groupe code sa bibliothèque ; dix bibliothèques se branchent entre elles via une API commune et répondent exactement pareil au même contrat.

Le contexte détaillé, les règles du moteur, les livrables de l'atelier et le calendrier sont dans [CLAUDE.md](CLAUDE.md).

## Contenu du dépôt

- `CLAUDE.md` : résumé du sujet et consignes de travail.
- `laravel-babel/` : dépôt séparé, non suivi ici.
