# frontend : application web (R5.05)

Angular + TypeScript, Tailwind CSS, signals, RxJS, intercepteurs et guards, Echo + Reverb pour le temps réel, SSR.

Le projet Angular sera créé ici avec le cours R5.05 (à partir du 4 décembre).

Ce que ce dossier devra contenir, d'après le [cahier des charges](../docs/cahier-des-charges.md) :

- le lecteur de pages, la navigation, la recherche locale et réseau, l'espace membre ;
- `localiser` (F4) et `voisine` (F6), calculés dans le navigateur (entiers sans limite de taille pour l'hexagone) ;
- l'abonnement au canal temps réel **avant** de lancer une recherche réseau ;
- aucun appel direct à une autre bibliothèque : tout passe par notre serveur.
